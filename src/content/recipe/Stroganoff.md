## Ingrediënten

| #:     | Ingredient:             |
| ------ | ----------------------- |
| 1      | Biefstuk of varkenshaas |
| 1 stuk | ui                      |
| 250g   | champignons             |
| 200ml  | bouillon                |
| 100g   | zure room               |
| ~2tl   | maizena                 |
|        | whiskey/cognac          |
|        | peper                   |
|        | zout                    |
|        | tijm                    |
|        | knoflookpoeder          |
|        | paprikapoeder           |

## Bereiding

1. Snij het vlees in stukjes en bestrooi met zout en peper en bak in een hete pan en leg het opzij. Het vlees kookt door tijdens het rusten en later in de saus, dus bak niet te ver door.

2. Snipper de ui en snij de champingons. Bak in dezelfde pan als het vlees.

3. Als het vocht uit de champignons verdreven is, voeg dan een scheut whiskey of cognac toe en laat inkoken.

4. Voeg de bouillon toe. Meng de maizena met koud water of bouillon en meng het al roerende in de saus. Maak het wat dikker, want de zure room zal het later weer uitdunnen.

5. Voeg mosterd, knoflookpoeder, paprikapoeder, tijm, zout en peper naar wens toe.

6. Voeg de zure room toe. Laat het smelten en roer goed door. Voeg het vlees toe. Serveer met pasta.
