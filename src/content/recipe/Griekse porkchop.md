## Ingrediënten

| #: | Ingredient: | kcal: |
| --- | ----------- | ----: |
| 2 stuks à 400g | schouderkarbonade | 740 |
| | olijfolie | 100 |
| 2 teentjes | knoflook | |
| 1 à 2 el | citroensap | |
| | zout | |
| | peper | |
| | oregano | |
| | totaal: | 840 |

## Bereiding

1. Pers de knoflook en meng met de olie, het citroensap, peper, zout en oregano.
2. Marineer de karbonades minstes 30 min, liefst 2 tot 4 uur.
3. Bak de karbonades naar wens.
